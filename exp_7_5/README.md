# 实验 7.5：在 7.4 基础上加入数据存储器访存

本目录是对 `exp_7_4` 的增量扩展，重点实现 `lw/sw` 访存通路。

## 1. 本实验新增内容（相对 7.4）

- 新增数据存储器 `Data_RAM`，支持读写。
- 译码器新增访存控制信号：`mem_wen`、`mem_to_reg`。
- 写回路径从“仅 ALU 结果”扩展为“ALU/内存二选一”。
- 顶层增加拨码选择显示：指令字、访存地址、访存读数据、ALU 结果。

## 2. 目录与文件说明

- `exp_7_5.srcs/sources_1/new/`：手写 RTL 源码。
- `exp_7_5.srcs/sim_1/new/top_sim.v`：仿真 testbench。
- `Inst_ROM.coe`：指令 ROM 初始化内容。
- `Data_RAM.coe`：数据 RAM 初始化内容。
- `bit/top.bit`：本实验可下载 bitstream（已放入仓库）。
- `docs/`：本实验的 RTL/电路图存放目录。

## 3. Bit 文件

- `bit/top.bit` 是本实验当前版本的上板文件。
- 由 `exp_7_5.xpr` 的 `impl_1` 运行 `write_bitstream` 生成。
- 使用前请确认约束文件与开发板型号一致。

## 4. RTL 图与电路图

- RTL 图：展示 CPU + Data_RAM 的结构与信号连接。
- 电路图：展示综合后在 FPGA 资源上的映射结果。
- 本目录预留 `docs/` 存放截图，便于按实验独立检查。

## 5. COE 文件含义

- `Inst_ROM.coe`：测试程序机器码。
- `Data_RAM.coe`：初始内存数据（用于验证 `lw/sw` 结果）。

## 6. 继承关系说明

- 7.5 代码是在 7.4 的结构上增量修改，核心模块命名保持一致。
- 建议先看 7.4，再看 7.5 的新增控制与访存路径。
